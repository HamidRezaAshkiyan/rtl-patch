پیش‌نمایش زنده ابزارهای پشتیبانی‌شده راهنمای نصب و اجرا گیت‌هاب
مک‌او‌اس • لینوکس • ویندوز • بدون وابستگی اضافه

پشتیبانی کامل فارسی و راست‌به‌چپ برای ابزارهای کدنویسی هوش مصنوعی

فقط با یک دستور، نمایش متون فارسی، عربی و عبری را در Cursor، چت VS Code Copilot، افزونه‌های هوشمند (Cline، Claude Code و…) و OpenCode اصلاح کنید — بدون اینکه بلوک‌های کد به هم بریزند و با اعمال خودکار دوباره بعد از هر آپدیت.

شروع سریع و نصب مشاهده سورس در گیت‌هاب
git clone https://github.com/HamidRezaAshkiyan/rtl-patch.git && cd rtl-patch && npm install && npm run build && npm link

مقایسه زنده قبل و بعد از پچ

دکمه زیر را تغییر دهید تا ببینید چطور با rtl-patch متن‌های فارسی کاملاً خوانا و راست‌به‌چپ می‌شوند، در حالی که کدها و نام فایل‌ها چپ‌به‌راست باقی می‌مانند.

پنل چت هوش مصنوعی (VS Code / Cursor / OpenCode)
پاسخ دستیار هوشمند

برای اعمال پچ راست‌به‌چپ روی همه ابزارهای نصب‌شده، کافیست دستور rtl-patch apply را اجرا کنید. بلوک‌های کد و مسیر فایل‌ها مثل src/cli.ts همیشه به صورت چپ‌به‌راست نمایش داده می‌شوند: 

// Code blocks always remain strictly LTR
rtl-patch apply --rtl-font "Vazirmatn, sans-serif"
rtl-patch watch --install

هر زمان هم که بخواهید همه چیز به حالت اول برگردد، با دستور rtl-patch revert فایل‌های اصلی دقیقاً از بکاپ بازیابی می‌شوند.

ابزارهای پشتیبانی‌شده

معماری ماژولار با بکاپ خودکار، رفع خطای corrupt شدن VS Code/Cursor و قابلیت بازگشت کامل به حالت اولیه.

Cursor cursor

راست‌به‌چپ‌سازی چت هوش مصنوعی، Composer و باکس ورودی پیام همراه با به‌روزرسانی خودکار checksum فایل product.json.

VS Code vscode

پشتیبانی از Copilot Chat و همچنین وب‌ویو افزونه‌های معروف مثل Claude Code، Cline، Roo Code، Kilo Code، Continue و Gemini Code Assist.

OpenCode opencode

نصب پلاگین مستقل فارسی‌ساز (چسباندن حروف و مرتب‌سازی BiDi در ترمینال) بدون دستکاری تاریخچه ارسال‌شده به مدل هوش مصنوعی.

آپدیت خودکار watch

پس از آپدیت شدن VS Code یا Cursor، پچ را به‌طور خودکار دوباره اعمال می‌کند (سرویس پس‌زمینه برای مک، لینوکس و ویندوز).

راهنمای سریع نصب و استفاده

فقط نیاز به Node.js 18+ دارید. در ۳ مرحله ساده فعال می‌شود:

۱

نصب ابزار

مخزن را کلون کنید و با npm link دستور rtl-patch را در کل سیستم در دسترس قرار دهید.

۲

اعمال پچ

دستور rtl-patch apply را اجرا کنید و ادیتور یا OpenCode را یک بار ببندید و باز کنید.

۳

فعال‌سازی پس‌زمینه (اختیاری)

با rtl-patch watch --install دیگر نگران پاک شدن پچ بعد از آپدیت ادیتور نخواهید بود.

# بررسی ابزارهای نصب‌شده و وضعیت فعلی پچ
rtl-patch status

# پیش‌نمایش تغییرات بدون تغییر دادن هیچ فایلی
rtl-patch apply --dry-run

# اعمال پچ فارسی/راست‌به‌چپ روی همه ابزارهای پیدا‌شده
rtl-patch apply

# اعمال پچ همراه با فونت فارسی دلخواه (مثلاً وزیرمتن)
rtl-patch apply vscode cursor --rtl-font "Vazirmatn, Tahoma, sans-serif"

# نصب سرویس پس‌زمینه برای اعمال خودکار دوباره پس از آپدیت ادیتورها
rtl-patch watch --install

# بازگرداندن کامل همه فایل‌ها به حالت اولیه از روی بکاپ
rtl-patch revert

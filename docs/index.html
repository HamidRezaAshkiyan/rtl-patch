برای اعمال پچ RTL روی همه ایجنت‌های نصب‌شده، کافیست دستور rtl-patch apply را اجرا کنید. بلوک‌های کد و مسیر فایل‌ها مثل src/cli.ts همیشه چپ‌به‌راست باقی می‌مانند: 

// Code blocks always remain strictly LTR
rtl-patch apply --rtl-font "Vazirmatn, sans-serif"
rtl-patch watch --install

اگر هر زمان خواستید همه تغییرات را برگردانید، rtl-patch revert فایل‌های اصلی را بایت‌به‌بایت از بکاپ بازیابی می‌کند.

Supported Targets

Modular driver architecture with clean backups, integrity checksum handling, and byte-exact revert.

Cursor cursor

CSP-safe CSS + Trusted-Types-safe MutationObserver for AI Chat, Composer, and chat inputs, with automatic product.json checksum updates.

VS Code vscode

Patches Copilot Chat plus installed AI extension webviews (Claude Code, Cline, Roo Code, Kilo Code, Continue, Gemini Code Assist).

OpenCode opencode

Installs a self-contained ESM plugin with Arabic/Persian contextual shaping & BiDi reordering while keeping LLM message history clean.

Auto-Repatch Watcher watch

Survives IDE auto-updates via native background services: macOS LaunchAgent, Linux systemd user unit, or Windows Startup launcher.

CLI Commands

Simple, safe, and reversible.

# Inspect detected agents & current RTL patch state
rtl-patch status

# Preview changes without touching any files
rtl-patch apply --dry-run

# Apply RTL patches to all detected agents
rtl-patch apply

# Apply with a custom Persian/Arabic font
rtl-patch apply vscode cursor --rtl-font "Vazirmatn, Tahoma, sans-serif"

# Install background watcher to auto-repatch after IDE updates
rtl-patch watch --install

# Cleanly revert all patches & restore original backups
rtl-patch revert
